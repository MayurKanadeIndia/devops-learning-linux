## 1. Navigation & Directory Listing

### `pwd` (Print Working Directory)
Displays the full path of your current directory.
```bash
pwd
# Output: /home/username/projects
```

### `ls` (List Directory Contents)
Lists files and folders in a directory.
* `-l`: Long listing format (shows permissions, owner, size, and modification date).
* `-a`: Shows hidden files (files starting with `.`).
* `-h`: Human-readable file sizes (e.g., `KB`, `MB`, `GB`).

```bash
ls -lah /var/log
```

### `cd` (Change Directory)
Moves you between directories.
```bash
cd /etc/nginx       # Move to an absolute path
cd ..               # Move up one directory level
cd ~                # Move to your home directory
cd -                # Switch back to the previous directory
```

## 2. Creating Files & Directories

### `touch`
Creates an empty file or updates the access/modification timestamps of an existing file.
```bash
touch index.html style.css app.js
```

### `mkdir` (Make Directory)
Creates new directories.
* `-p`: Creates parent directories as needed without throwing an error if they already exist.

```bash
mkdir projects
mkdir -p projects/2026/linux-guide/assets
```

## 3. Viewing & Reading Files

### `cat` (Concatenate)
Displays the entire content of a file in the terminal. Best used for short files.
```bash
cat config.yaml
```

### `less`
Opens large files in a scrollable, interactive viewer without loading the whole file into memory.
* Press `Space` to move down a page, `b` to move up, `/keyword` to search, and `q` to quit.

```bash
less /var/log/syslog
```

### `head` & `tail`
Displays the beginning (`head`) or end (`tail`) of a file. By default, both show 10 lines.
* `-n`: Specifies the exact number of lines to show.
* `-f` (with `tail`): Follows the file in real time as new lines are added (ideal for live logs).

```bash
head -n 20 access.log
tail -n 15 error.log
tail -f /var/log/auth.log
```

## 4. Copying, Moving & Renaming

### `cp` (Copy)
Copies files or directories from a source to a destination.
* `-r`: Recursive (required when copying directories).
* `-i`: Interactive (prompts before overwriting an existing file).
* `-v`: Verbose (prints each file as it is copied).

```bash
cp notes.txt notes_backup.txt
cp -riv ./src ./backup_src
```

### `mv` (Move / Rename)
Moves files/directories to a new location or renames them in place.
* `-i`: Prompts before overwriting an existing destination file.

```bash
# Rename a file
mv draft.md README.md

# Move a file to another directory
mv README.md ~/projects/linux-guide/
```

## 5. Deleting Files & Directories

> **Warning:** Linux does not have a "Trash" or "Recycle Bin" for terminal commands. Deleted files are permanently removed.

### `rm` (Remove)
Deletes files and directories.
* `-r`: Recursive (deletes a directory and all its contents).
* `-i`: Interactive (asks for confirmation before every deletion).
* `-f`: Force (ignores nonexistent files and never prompts).

```bash
rm old_script.sh
rm -ri ./temp_folder
```

### `rmdir` (Remove Empty Directory)
Safely deletes a directory **only** if it is completely empty.
```bash
rmdir empty_folder
```

## 6. Searching & Finding Files

### `find`
Searches for files and directories based on name, type, size, or modification time.
```bash
# Find all .log files inside /var/log
find /var/log -name "*.log"

# Find only directories named "config" in the current path
find . -type d -name "config"

# Find files larger than 100MB
find /home -type f -size +100M
```

### `grep` (Global Regular Expression Print)
Searches for specific text patterns inside files.
* `-i`: Case-insensitive search.
* `-r`: Recursive search across all files in a directory.
* `-n`: Displays the line number where the match was found.

```bash
grep -rin "error" /var/log/nginx/
```

## 7. Permissions & Ownership

Linux file permissions are divided into **User (u)**, **Group (g)**, and **Others (o)**, with three permission types: **Read (`r` = 4)**, **Write (`w` = 2)**, and **Execute (`x` = 1)**.

### `chmod` (Change Mode)
Modifies read, write, and execute permissions.
```bash
# Make a script executable for the owner
chmod u+x deploy.sh

# Set standard permissions (rwxr-xr-x) using octal notation
chmod 755 deploy.sh

# Restrict a private key so only the owner can read/write it
chmod 600 id_rsa
```

### `chown` (Change Owner)
Changes the user and/or group ownership of a file or directory.
* `-R`: Applies the ownership change recursively to a directory and everything inside it.

```bash
sudo chown www-data:www-data /var/www/html/index.html
sudo chown -R username:developers ./project_folder
```

## 8. Archiving & Compression

### `tar` (Tape Archive)
Bundles multiple files into a single archive file and optionally compresses it.
* `-c`: Create a new archive.
* `-x`: Extract an existing archive.
* `-z`: Filter the archive through `gzip` (`.tar.gz`).
* `-v`: Verbose output.
* `-f`: Specify the archive filename.

```bash
# Create a compressed archive
tar -czvf backup.tar.gz ./project_folder

# Extract a compressed archive
tar -xzvf backup.tar.gz -C /destination/path
```

### `zip` & `unzip`
Creates and extracts standard `.zip` archives.
```bash
zip -r archive.zip ./documents
unzip archive.zip -d ./extracted_files
```
